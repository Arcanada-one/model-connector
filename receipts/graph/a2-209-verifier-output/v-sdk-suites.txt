A2-209 — SDK suites (targeted_test for packages/*, which the root vitest job does not cover)
===========================================================================================

The repository's root `pnpm vitest run` does not include packages/sdk-ts or packages/sdk-python,
so the graph verifier reports targeted_test as not_measured for every entity under packages/.
They were run explicitly instead; this file is that measurement.

[sdk-ts]  cd packages/sdk-ts && pnpm vitest run

      Tests  18 passed (18)
[sdk-ts]  npx tsc --noEmit -p tsconfig.json
  rc=0, clean

[sdk-python]  pytest -q
  ....................                                                     [100%]
  20 passed in 0.11s

Red-on-main, per SDK:
  sdk-python — 2 failed, 18 passed without the models.py change:
    AttributeError: 'ExecuteResponse' object has no attribute 'model_substituted'
  sdk-ts — STAYS GREEN (18 passed), tsc stays clean. That is a gap in the harness,
    not a pass: packages/sdk-ts/tsconfig.json has "exclude": ["dist","node_modules","test"],
    so no test in that package is ever type-checked, and no test there can go red on a
    type-only change. The TS field is therefore verified only by tsc over src/ and by
    the python SDK's equivalent assertion. Recorded as not_measured, and filed as a
    tooling defect.
